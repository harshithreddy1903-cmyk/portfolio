## 🌌 About The Project

This is a high-fidelity, single-page professional portfolio designed with a distinct "Dark Space" aesthetic. It breaks away from traditional grid-based layouts by utilizing an interactive, SVG-powered constellation map as the primary navigation system.

The background is a persistent HTML5 canvas generating 280 procedural stars that slowly twinkle and react via parallax scrolling. The content is presented in sleek glassmorphic panels that dynamically appear as you scroll down.

### ✨ Key Features

* **Interactive Constellation Navigation:** Beautiful SVG star nodes with glowing halos, pulse rings, and hover tooltips that navigate smoothly across sections.
* **Procedural Star Field:** High-performance, fixed canvas background using `requestAnimationFrame` for twinkling logic and scroll-triggered parallax.
* **Premium Glassmorphism:** Custom CSS `.section-panel` utilities with elegant `panel-shimmer` borders and soft blur backdrops.
* **Staggered Animations:** Every element enters the viewport with carefully timed delays, easing curves, and opacity fades powered by Framer Motion.
* **Typography:** A sophisticated dual-font system using *Cormorant Garamond* for beautiful italic headings and *Inter* for crisp body text.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Ensure you have Node.js installed on your machine.
* npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

1. Clone the repository
   ```sh
   git clone https://github.com/harshithreddy1903-cmyk/portfolio.git
   ```
2. Navigate into the directory
   ```sh
   cd portfolio
   ```
3. Install dependencies
   ```sh
   npm install
   ```
4. Start the development server
   ```sh
   npm run dev
   ```
5. Open your browser and navigate to `http://localhost:5174`
