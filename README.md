## 🚀 Run Locally

### Prerequisites

- Node.js **22.12 or newer** and npm.
- Git, if cloning from the command line.

### Setup

```sh
git clone https://github.com/harshithreddy1903-cmyk/portfolio.git
cd portfolio
npm ci
npm run dev
```

Open the **Local URL printed by Vite** in the terminal. The port can change if another application is already using it.

### Build and Preview

```sh
npm run build
npm run preview
```

The build command checks TypeScript and generates the production site in `dist/`. Open the preview URL printed in the terminal to view that build locally.

### Available Commands

| Command | Purpose |
| --- | --- |
| `npm ci` | Install the versions recorded in `package-lock.json` |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Check TypeScript and generate the production build |
| `npm run preview` | Serve the production build locally |
| `npm run lint` | Run the configured ESLint checks |

- Edit the section components in `src/components/` to update the profile, projects, skills and contact details.
